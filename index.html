fckingGoodOptimizer

Comprehensive Windows optimization toolbox focused on improving system performance, game experience and network responsiveness via advanced system tweaks and registry optimizations.

MIT License Windows 10 / 11 .NET 6 required
Repo & downloads
View on GitHub Details

🚀 Performance Tweaks

GPU, RAM and SSD tuning, visual effect trims, and power-plan adjustments to squeeze max performance.

🎮 Gaming Optimizations

Game mode setup, fullscreen optimizations, DirectX and overlay tweaks for smoother framerates.

🌐 Network Enhancements

DNS tuning (e.g. Cloudflare), IPv6 tweaks, and TCP/IP stack fine-tuning to reduce latency.

Installation

  • Requirements: Windows 10/11, .NET 6.0 Runtime, Admin privileges.
  • Run the app as administrator and choose optimization categories.
  • Reboot when prompted to apply system-level changes.

⚠️ Warning

Some tweaks may affect stability. Create a system restore point before applying critical changes.

Technical notes: registry edits, PowerShell integrations, multi-threaded tasks, and robust logging are included.
