~/about

Close to the metal.

I'm erhicaldc, a software developer and systems enthusiast. I like the layers most people never look at: how packages get fetched, resolved and compiled, how Windows can be tuned for games and low latency, and how complicated logic can become something you wire together visually.

My projects span C11 on Linux From Scratch, .NET on Windows and Electron on the desktop. Different stacks, same goal: fast, well-structured software.

  • Systems

    C11, GNU Make, libcurl and cJSON. Source builds, staging roots and dependency graphs.

  • Windows

    .NET 6 tooling, registry and system tweaks, PowerShell integrations.

  • Desktop apps

    Electron, the Monaco editor and node-based visual editors.

  • Languages

    C, C#, JavaScript, Python and Lua.

nxpm

NexaPackageManager

A minimalist, source-based package manager written in C11 and engineered specifically for Linux From Scratch environments. It automates fetching, dependency resolution and compilation.

  1. fetchsources
  2. resolverecursive
  3. buildBUILD_ROOT
  4. deployatomic
  5. indexfiles
  • Staging-first logic: builds land in BUILD_ROOT first
  • Recursive dependency resolution
  • Atomic deployment and file indexing

fckingGood​Optimizer

Windows optimization toolbox · .NET 6

A comprehensive toolbox for Windows 10 and 11 focused on system performance, game experience and network responsiveness, applied through advanced system tweaks and registry optimizations.

  • Performance tweaks

    GPU, RAM and SSD tuning, visual effect trims and power-plan adjustments.

  • Gaming optimizations

    Game Mode setup, fullscreen optimizations, DirectX and overlay tweaks.

  • Network enhancements

    DNS tuning, IPv6 tweaks and TCP/IP stack fine-tuning to reduce latency.

No longer maintained. The repository stays up for reference; create a system restore point before trying any system-level tweak.

  • .NET 6
  • Windows 10 / 11
